# Pinnacle enquiry form (Salesforce Web-to-Lead demo)

Concept demo of a Web-to-Lead enquiry form prepared for a Pinnacle Group Sales Cloud demo. Not an official Pinnacle Group page.

Live page: https://akhil8790.github.io/pinnacle-enquiry-demo/

Submitting the form creates a Lead in the demo Salesforce org. There, automation fills in the project and region, routes the lead to the regional queue and the sales executive, creates a "Call within 1 hour" task, and sends a branded acknowledgement email.
